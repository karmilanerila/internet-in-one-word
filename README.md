An entry for [The Internet in One Word](https://make.fun/c/u-ronigrv-the-internet-in-one-word-e388f33b?ref=h379tqrk) on make.fun.

The program writes a single word to `/output/entry.txt`: **enshittification** — the slow decay of every platform on the internet as it gets worse for its users while extracting more from them. It names the whole internet, not one app; it is funny on its own; and it is not the first word anyone reaches for.

Run it with Python 3.13 (stdlib only, no network):

```sh
python3 main.py
```
